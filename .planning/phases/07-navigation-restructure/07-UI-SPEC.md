# Phase 07 — UI Design Contract

> Visual and interaction contract for Phase 07: Navigation Restructure.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — pure Tailwind CSS utility classes |
| Preset | not applicable |
| Component library | none (vanilla React + Tailwind) |
| Icon library | inline SVG (stroke-based, 1.5 stroke width, round caps/joins) |
| Font | Inter via `var(--font-inter)` CSS custom property |

_Source: codebase scan — `tailwind.config.ts`, `index.css`, `feed/page.tsx`_

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge positioning, inline nudges |
| sm | 8px | Between icon and label in tab items, button padding |
| md | 16px | Default element padding, horizontal tab content padding |
| lg | 24px | Section top padding, content top clearance |
| xl | 32px | Major section breaks in Inbox/Integrations lists |
| 2xl | 48px | Tab bar height (56px = 48px + 8px top padding for touch target) |
| 3xl | 64px | Sidebar nav header height + safe-area clearance on desktop |

Exceptions:
- Bottom tab bar total height: **56px** intrinsic + `env(safe-area-inset-bottom)` padding-bottom (iOS home indicator clearance)
- Sidebar width: **240px** (fixed; not on the 8pt scale but standard sidebar convention)
- Desktop content offset: `ml-[240px]` matching sidebar width exactly
- Tab icon touch target: minimum **44×44px** per platform accessibility guidelines (met by `flex-1 flex flex-col items-center pt-2 pb-1 min-h-[56px]`)
- Content area bottom padding when bottom nav is visible: `pb-[calc(4rem+env(safe-area-inset-bottom))]` — accounts for 56px tab bar + 8px clear

## Typography

|------|------|--------|-------------|----------------|
| Body | 14px | 400 regular | 1.5 | `text-sm` |
| Label / caption | 10–10.5px | 600 semibold | 1.2 | `text-[0.65rem] font-semibold` |
| Section header (caps) | 10–10.5px | 600 semibold | 1.2 | `text-[0.65rem] font-semibold uppercase tracking-[0.1em]` |

Tab bar labels: `text-[0.65rem] font-semibold uppercase tracking-[0.08em]`
— same size tier as label/caption but tighter tracking distinguishes navigation chrome from content.

Day/Week toggle labels: `text-[0.65rem] font-semibold capitalize`
— matches existing segmented control in feed/page.tsx.

## Color

| Role | Value | Tailwind Alias | Usage |
|------|-------|----------------|-------|
| Dominant (60%) | `#ffffff` | `white` / `bg-white` | All content surfaces, tab bar background, sidebar background |
| Secondary (30%) | `#f4f4f5` / `#e4e4e7` | `zinc-100` / `zinc-200` | Borders, dividers (`border-zinc-100`), hover states (`hover:bg-zinc-50`), active sidebar item highlight (`bg-zinc-100`) |
| Accent (10%) | `#18181b` | `black` / `zinc-900` | Active tab icon + label, active Day/Week toggle pill, primary action buttons ("Schedule", "Connect"), active sidebar item text, nav wordmark |
| Destructive | `#ef4444` | `red-500` | Disconnect integration action only |

**Accent reserved for:**
1. Active tab bar item (icon + label)
2. Active Day/Week toggle pill (filled background + white text)
3. Primary CTAs: "Schedule" (Inbox), "Connect" (Integrations)
4. Inbox badge count bubble (bg-black text-white)
5. Active sidebar nav item (bg-zinc-100 + text-black + font-semibold)

**Inactive / resting states:** `text-zinc-400` for tab icons and labels, sidebar items, section metadata.

**Service source badge colors (read-only dots, not interactive):**
- Gmail: `#EA4335`
- Apple Calendar: `#34C759`
- Microsoft To Do: `#0078d4`
- ordrctrl native: `#18181b`

**Sync status indicator colors:**
- Connected: `bg-green-500` (dot, 8px)
- Syncing / pending: `bg-amber-400` (dot, 8px)
- Error: `bg-red-500` (dot, 8px)
- Disconnected: `bg-zinc-300` (dot, 8px)

## Component Contracts

### 1. Bottom Tab Bar (mobile, `< 768px`)

**Container:**
```
fixed bottom-0 left-0 right-0
flex
bg-white border-t border-zinc-100
z-30
pb-[env(safe-area-inset-bottom)]
```

**Per tab item (flex-1, one of three):**
```
flex-1 flex flex-col items-center justify-center
pt-2 pb-1 gap-0.5
min-h-[56px]
cursor-pointer select-none
transition-colors
```

**Tab icon:** 22×22 SVG, `stroke="currentColor"`, `strokeWidth="1.5"`, `strokeLinecap="round"`, `strokeLinejoin="round"`. Filled only for active state (use `fill="currentColor"` or thicker stroke on active).

**Tab label:** `text-[0.65rem] font-semibold uppercase tracking-[0.08em]`

**Active state:** `text-black` (icon + label)
**Inactive state:** `text-zinc-400` (icon + label)

**Inbox badge:**
```
absolute -top-1 -right-1
w-4 h-4
bg-black text-white
text-[0.55rem] font-semibold
rounded-full
flex items-center justify-center leading-none
```
Display: count if ≤ 9, `"9+"` if > 9. Hidden when count = 0. The tab icon container must be `relative` to anchor the badge.

**Icons (inline SVG, 22×22 viewBox 0 0 24 24):**
- **Planner:** calendar grid icon — `<rect x="3" y="4" width="18" height="18" rx="2"/><path d="M3 9h18M8 2v4M16 2v4"/>`
- **Inbox:** inbox tray icon — `<path d="M4 4h16v12H4z"/><path d="M4 16l4-4h8l4 4"/>` (existing icon already used in feed/page.tsx)
- **Integrations:** plug/connection icon — `<path d="M7 7l-5 5 3 3 5-5M17 17l5-5-3-3-5 5M14 5l5 5M5 14l5 5M9 9l6 6"/>`

```
flex items-baseline gap-2 px-5 pt-6 pb-4 flex-shrink-0
```
- Title: `text-base font-semibold text-zinc-900` → "Inbox"
- Count badge (inline text, not a pill): `text-xs text-zinc-400` → "{N} items"

**Section header (per integration group):**
```
text-[0.65rem] font-semibold uppercase tracking-[0.1em] text-zinc-400
pb-1 mb-1 border-b border-zinc-100
```
Content: `{ServiceName}` (e.g. "Gmail", "Microsoft To Do", "Apple Calendar")

**Inbox item row:**
```
flex items-start justify-between gap-3
py-3 border-b border-zinc-100 last:border-b-0
```

Item row sub-anatomy:
- **Left cluster** (`flex items-start gap-2 min-w-0 flex-1`):
  - Type glyph: `text-zinc-400 text-xs mt-0.5 shrink-0` — `↗` task, `⏰` event, `✉` email
  - Title: `text-sm text-zinc-900 truncate`
  - Existing date (if any): `text-xs text-zinc-400 mt-0.5`
  - Source service dot: 6px circle, service color from palette above, `inline-block mr-1`
- **Right cluster** (`flex items-center gap-1 shrink-0`):
  - **"Schedule" CTA** — `px-2 py-1 text-xs font-semibold text-white bg-black hover:bg-zinc-800` (no border-radius — matches existing sharp button style)

**Date picker affordance for "Schedule":** tapping "Schedule" opens the existing `EditTaskModal` (or a future date-picker sheet) pre-filled with today's date. No inline date picker on the row — modal pattern only.

## Responsive Breakpoint Behavior

| Viewport | Navigation | Content area | Top bar |
|----------|------------|--------------|---------|
| `< 768px` (mobile) | Fixed bottom tab bar (56px + safe-area) | Full width, `pb-[calc(3.5rem+env(safe-area-inset-bottom))]` | 48px fixed top: wordmark + AccountMenu |
| `≥ 768px` (desktop) | Fixed left sidebar (240px) | `ml-[240px]` full height | None — wordmark + AccountMenu live in sidebar header |

**Breakpoint class:** `md:` prefix (`768px`) — matches existing Tailwind default and the NAV-05 requirement.

**Transition:** No animated transition at the breakpoint. The layout switch is instantaneous (CSS responsive classes only, no JS media query listener needed).

**FAB (floating action button):** Preserved on Planner tab only. Position: `fixed bottom-[calc(1.5rem+env(safe-area-inset-bottom))] right-6` on mobile. On desktop (≥768px): `fixed bottom-6 right-6` (no bottom nav to clear).

## Implementation Notes for Executor

1. **Routing:** The three tabs map to existing routes. Tab bar/sidebar are layout-level components wrapping all authenticated routes. Active tab is determined from `useLocation()` matching `/feed` → Planner, `/inbox` → Inbox, `/settings/integrations` → Integrations.

2. **Planner tab content:** `DailyPlannerView` (default) and `WeeklyPlannerView` already exist. The Day/Week toggle replaces the old 5-mode segmented control. Remove `feed`, `timeline`, `list` from the toggle — keep only `planner` (Day) and `week` (Week) modes.

3. **Inbox tab content:** `InboxPage` component already exists at `frontend/src/components/inbox/InboxPage.tsx`. Adapt for the new nav shell — remove its standalone top bar (wordmark + back link), replace with the shared app shell header.

4. **Integrations tab content:** `IntegrationSettingsContent` already exists at `frontend/src/app/settings/integrations/page.tsx`. Adapt for the new nav shell — remove its standalone back-navigation pattern.

5. **No @apply, no inline style** except runtime-dynamic values (e.g. `style={{ top: nowTop }}` in timeline). All layout is pure Tailwind utility classes.

6. **No swipe gesture for tab navigation** — confirmed locked decision (conflicts with timeline horizontal scroll in Week mode).

7. **Inbox badge count:** reuse existing `useInboxCount` hook already imported in `feed/page.tsx`.
