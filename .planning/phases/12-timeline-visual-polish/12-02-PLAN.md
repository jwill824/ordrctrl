<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API (color/icon input) | Hex color strings and emoji strings cross trust boundary at PATCH /api/tasks/:id and PATCH /api/feed/:itemId/override |
| client→API (itemId param) | URL param `itemId` must be validated to prevent accidental access to native task overrides |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-12-02-01 | Tampering | PATCH /api/tasks/:id color field | mitigate | `z.string().regex(/^#[0-9a-fA-F]{6}$/)` enforces valid 6-char hex; rejects CSS expressions, XSS payloads |
| T-12-02-02 | Tampering | PATCH /api/feed/:itemId/override icon field | mitigate | `z.string().max(10)` limits to 10 chars; sufficient for emoji, blocks large payloads |
| T-12-02-03 | Tampering | PATCH /api/feed/:itemId/override itemId | mitigate | Validate `sync:` prefix; userId scopes the DB query to prevent cross-user override writes |
| T-12-02-04 | Information Disclosure | SyncOverride upsert | accept | Color/icon data is low-sensitivity; DB constraint `@@unique([syncCacheItemId, overrideType])` prevents duplicates |
| T-12-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan |
</threat_model>
