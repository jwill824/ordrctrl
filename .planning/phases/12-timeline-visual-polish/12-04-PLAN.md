       ```

       ```

    2. Update the `TaskSheetProps` interface — change `onSave` to:
       ```
       onSave: (title: string, startAt: string, durationMinutes: number, isAllDay: boolean, color: string, icon: string | null) => Promise<void>;
       ```

    3. Add two state variables after the existing ones:
       ```
       const [color, setColor] = useState<string>(task?.color ?? '#3B82F6');
       const [hexInput, setHexInput] = useState<string>(task?.color ?? '#3B82F6');
       const [icon, setIcon] = useState<string>(task?.icon ?? '');
       ```
       `hexInput` is a separate string that tracks the text input value before validation, preventing the input from clearing mid-type.

    4. In `handleSubmit`, update the `onSave` call to pass two new trailing args:
       ```
       await onSave(title.trim(), newStartAt.toISOString(), durationMinutes, isAllDay, color, icon.trim() || null);
       ```

    5. In the JSX, add a color + icon section immediately after the title `<input>` field and before the time picker row. Structure:

       **Color swatch row (8 tappable circles):**
       ```
       <div className="flex gap-2 mt-3">
         {PALETTE.map((hex) => (
           <button
             key={hex}
             type="button"
             className={`w-7 h-7 rounded-full border-2 border-white ${color === hex ? 'ring-2 ring-offset-1 ring-black' : ''}`}
             style={{ backgroundColor: hex }}
             onClick={() => { setColor(hex); setHexInput(hex); }}
             aria-label={`Select color ${hex}`}
             aria-pressed={color === hex}
           />
         ))}
       </div>
       ```

       **Custom hex input (below swatches):**
       ```
       <div className="flex items-center gap-2 mt-2">
         <div className="w-5 h-5 rounded-sm border border-zinc-200" style={{ backgroundColor: color }} />
         <input
           type="text"
           className="text-sm border border-zinc-200 rounded px-2 py-1 w-28 font-mono"
           value={hexInput}
           maxLength={7}
           placeholder="#3B82F6"
           onChange={(e) => {
             setHexInput(e.target.value);
             if (/^#[0-9a-fA-F]{6}$/.test(e.target.value)) {
               setColor(e.target.value);
             }
           }}
           onBlur={() => {
             if (!/^#[0-9a-fA-F]{6}$/.test(hexInput)) {
               setHexInput(color); // revert to last valid color
             }
           }}
         />
       </div>
       ```

       **Icon emoji input (below hex input):**
       ```
       <div className="mt-2">
         <label className="text-xs text-zinc-500 block mb-1">Icon (emoji)</label>
         <input
           type="text"
           className="text-sm border border-zinc-200 rounded px-2 py-1 w-20"
           value={icon}
           maxLength={10}
           placeholder="e.g. 🎯"
           onChange={(e) => setIcon(e.target.value)}
         />
       </div>
       ```

    All three new UI blocks should be inside a `<div className="px-4">` wrapper consistent with the sheet's existing horizontal padding pattern (check the surrounding layout and match it — do not guess at different padding).
