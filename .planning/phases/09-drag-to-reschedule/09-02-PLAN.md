    **Hook interface:**
    ```ts
    export type DragState = 'idle' | 'drag-move' | 'drag-resize' | 'persisting' | 'reverting' | 'error-tint';

    interface UseDragToRescheduleProps {
      item: PlannerItem;
      onReschedule: (taskId: string, newStartAt: string) => Promise<void>;
      onResize: (taskId: string, newDurationMinutes: number) => Promise<void>;
      onDragActiveChange?: (active: boolean) => void;
    }

    interface UseDragToRescheduleReturn {
      dragState: DragState;
      liveTop: number;
      liveHeight: number;
      revertTransition: string;
      startMove: (e: React.PointerEvent, blockEl: HTMLElement) => void;
      startResize: (e: React.PointerEvent, blockEl: HTMLElement) => void;
    }
    ```

    **Snap + clamp helpers (internal):**
    ```
    function computeNewStart(originalStartMin: number, deltaY: number): number {
      const deltaMin = (deltaY / PX_PER_HOUR) * 60;
      const raw = originalStartMin + deltaMin;
      return Math.max(0, Math.min(snapToGrid(raw), 24 * 60 - MIN_DRAG_DURATION_MINUTES));
    }

    function computeNewDuration(originalDurationMin: number, originalStartMin: number, deltaY: number): number {
      const deltaMin = (deltaY / PX_PER_HOUR) * 60;
      const raw = originalDurationMin + deltaMin;
      const snapped = Math.max(MIN_DRAG_DURATION_MINUTES, snapToGrid(raw));
      return Math.min(snapped, 24 * 60 - originalStartMin); // clamp end ≤ 1440
    }
    ```

    **Tap disambiguation:** In startMove, record `pointerDownTime = Date.now()`. In pointerUp
    handler: if totalDeltaY < DRAG_INTENT_THRESHOLD_PX AND elapsed < 200ms, treat as tap — reset
    to idle, call `onTap?.()` (no-op in Phase 09). Otherwise fire onReschedule.

    **Drag-move not declared until ≥ DRAG_INTENT_THRESHOLD_PX moved.** Before threshold: dragState
    remains 'idle' (liveTop tracks pointer), so the block doesn't visually lift until declared.

    **Document listener cleanup:** Use the AbortController pattern:
    ```ts
    const controller = new AbortController();
    document.addEventListener('pointermove', handlePointerMove, { passive: false, signal: controller.signal });
    document.addEventListener('pointerup', handlePointerUp, { signal: controller.signal });
    document.addEventListener('pointercancel', handlePointerCancel, { signal: controller.signal });
    // cleanup: controller.abort()
    ```
    Use a `useEffect` return to call `controller.abort()` on unmount.

    **Revert timing:** Use `setTimeout` (not useEffect) for the 300ms and 1500ms windows. Store
    timer ids in refs and clear them on unmount via useEffect cleanup to prevent memory leaks.

    **persisting guard:** While `dragState === 'persisting'`, the startMove and startResize
    functions must return early (no re-entry during in-flight API call).

    **ISO startAt computation:** Convert snapped minutes back to ISO string:
    ```ts
    const originalDate = new Date(item.startAt);
    const newDate = new Date(originalDate);
    newDate.setHours(Math.floor(snappedStartMin / 60), snappedStartMin % 60, 0, 0);
    const newStartAt = newDate.toISOString();
    ```
    (Note: item.startAt is the ORIGINAL date — preserve year/month/day from the dragged item.)

    The hook computes `liveTop` and `liveHeight` from `item` on initial render:
    ```ts
    const originalStartMin = item.startAt
      ? (new Date(item.startAt).getHours() * 60 + new Date(item.startAt).getMinutes())
      : 0;
    const originalTop = (originalStartMin / 60) * PX_PER_HOUR;
    const originalHeight = Math.max(BLOCK_MIN_HEIGHT, ((item.durationMinutes ?? 30) / 60) * PX_PER_HOUR);
    ```
    State initialises to these values. During drag: update liveTop / liveHeight on every pointermove.
    On revert: set back to originalTop / originalHeight.
