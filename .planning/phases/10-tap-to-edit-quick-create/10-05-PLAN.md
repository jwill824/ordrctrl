  <what-built>
    Phase 10 complete — tap-to-edit and quick-create UX implemented end-to-end:

    1. `useTaskSheet` hook — manages open/close state, create vs edit mode, selected task
    2. `useTaskSheet` integrated into `feed/page.tsx` — replaces showQuickCreate state
    3. `useDragToReschedule` — `onTap` callback fires on short tap (< 8px, < 200ms)
    4. `DraggableTimeBlock` — threads `onTap` prop to hook
    5. `DailyPlannerView` — wires `onTap` to call `onTap(item)` per block
    6. `TaskSheet` component — unified create + edit sheet with:
       - Single-column scroll-wheel time picker (15-min slots, full 24h range)
       - Duration stepper (+/- 15min, live label, floor 15min / ceiling 480min)
       - Edit mode prefill from task props
       - Delete button with "Are you sure?" confirm step
       - Slide-up animation, backdrop tap + swipe-down dismiss
    7. `TimeSlotPicker` adapter — thin wrapper around react-mobile-picker
    8. `timeSlots.ts` utility — generates 96 time slots, conversion helpers
    9. Full test suite GREEN: all tests pass including W0-A through W0-N
  </what-built>
  <how-to-verify>
    Start the dev server:
    ```bash
    pnpm dev
    ```
    Open http://localhost:3000 in your browser (or run on device via Capacitor for touch test).

    ---

    **Test 1 — Tap to edit (EDIT-01, SC-1):**
    1. Navigate to the Planner tab
    2. Ensure at least one native task is visible on the timeline (create one if needed)
    3. Short-tap the task block (quick click/touch, < 200ms, don't drag)
    4. Expected: TaskSheet slides up from bottom, pre-filled with the task's title, start time, and duration
    5. Verify: title input shows the correct task name
    6. Verify: time picker scrolled to the task's current start time slot
    7. Verify: duration label shows the task's duration in minutes

    ---

    **Test 2 — Save from edit sheet (EDIT-02, SC-2):**
    1. With the edit sheet open (from Test 1), change the start time by scrolling the time picker to a different slot
    2. Tap the save button
    3. Expected: sheet closes; timeline refreshes; task appears at the new time
    4. Reload the page — confirm the change persisted (was saved to the backend)

    ---

    **Test 3 — Scroll-wheel time picker (QC-01, SC-3):**
    1. Open TaskSheet (either via tap-to-edit or FAB)
    2. Scroll the time picker column
    3. Expected: a single scrollable list of times in 15-minute increments ("0:00", "0:15", ..., "23:45")
    4. Verify: it is ONE column (not separate hour and minute columns)
    5. Verify: scrolling snaps to a specific time slot

    ---

    **Test 4 — Duration stepper (QC-02, SC-4):**
    1. With TaskSheet open, locate the duration stepper
    2. Tap "+" — expected: duration increases by 15 minutes; label updates live (e.g., "30 min" → "45 min")
    3. Tap "−" — expected: duration decreases by 15 minutes
    4. Tap "−" repeatedly until floor (15 min) — expected: cannot go below 15 min
    5. Tap "+" until ceiling (480 min) — expected: cannot exceed 480 min

    ---

    **Test 5 — FAB opens create sheet:**
    1. Tap the "+" FAB button while in the Planner tab
    2. Expected: TaskSheet opens in create mode (title input empty, time picker at a rounded default time, duration defaults to 30 min)
    3. No delete button visible in create mode
    4. Enter a title, adjust time and duration, tap save
    5. Expected: new task appears on the timeline at the selected time

    ---

    **Test 6 — Tap disambiguation (no sheet on drag):**
    1. Click and hold a task block, drag it vertically (more than 8px of movement)
    2. Release
    3. Expected: block reschedules (Phase 09 behavior) — TaskSheet does NOT open
    4. Confirm: task moved to new time, no sheet appeared

    ---

    **Test 7 — Delete task (EDIT-02):**
    1. Tap a native task to open the edit sheet
    2. Tap the "Delete" button
    3. Expected: confirmation prompt appears ("Are you sure?") with "Yes, delete" and "Cancel"
    4. Tap "Cancel" — expected: back to normal edit state, task unchanged
    5. Tap "Delete" again → "Yes, delete"
    6. Expected: task removed from the timeline; sheet closes

    ---

    **Test 8 — Dismiss sheet:**
    1. Open the TaskSheet (either mode)
    2. Tap the backdrop (the dark overlay outside the sheet)
    3. Expected: sheet closes without saving
    4. Open it again and swipe down on the sheet
    5. Expected: sheet closes without saving

    ---

    **Test 9 — Sync item still uses EditTaskModal (regression):**
    1. If any sync items (Gmail, Google Calendar) are visible on the timeline or feed
    2. Tap one
    3. Expected: the old EditTaskModal opens (NOT the TaskSheet)
    4. Verify: EditTaskModal still allows updating due date and description override

    ---

    **Regression check:**
    1. Confirm drag-to-reschedule still works (Phase 09 behavior intact)
    2. Confirm drag-to-resize still works
    3. Navigate to week view — unaffected
    4. Navigate to Inbox tab — unaffected
    5. Run: `cd frontend && pnpm vitest run` — must exit 0

  </how-to-verify>
