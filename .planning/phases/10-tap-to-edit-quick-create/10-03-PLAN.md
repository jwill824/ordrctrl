  <files>frontend/src/components/tasks/TaskSheet.tsx</files>
  <behavior>
    Props interface (create mode — no task prop):
    - `defaultStartAt: string` — ISO string for default start time
    - `defaultDuration?: number` — default duration minutes (default: 30)
    - `onSave: (title: string, startAt: string, durationMinutes: number) => Promise<void>` — called with title, ISO startAt, and duration on submit
    - `onCancel: () => void`

    Props interface (edit mode — task prop present):
    - `task: PlannerItem` — pre-fills title, startAt, and durationMinutes
    - `onSave: (title: string, startAt: string, durationMinutes: number) => Promise<void>`
    - `onDelete: () => Promise<void>`
    - `onCancel: () => void`

    Combined interface (all props, task optional):
    ```tsx
    interface TaskSheetProps {
      task?: PlannerItem;
      defaultStartAt?: string;
      defaultDuration?: number;
      onSave: (title: string, startAt: string, durationMinutes: number) => Promise<void>;
      onDelete?: () => Promise<void>;
      onCancel: () => void;
    }
    ```

    State:
    - `title`: string — initialized from `task?.title ?? ''`
    - `slotValue`: string — initialized via `timeToSlotValue(task?.startAt ?? defaultStartAt)`
    - `durationMinutes`: number — initialized from `task?.durationMinutes ?? defaultDuration ?? 30`
    - `loading`: boolean
    - `error`: string | null
    - `confirmDelete`: boolean — controls "Are you sure?" confirm step

    isEditMode: `!!task`

    Submit handler:
    1. Prevents empty title or invalid duration
    2. Reconstructs ISO startAt from `slotValue`: take `defaultStartAt ?? task.startAt` for the DATE part, combine with hours/minutes from `slotValueToMinutes(slotValue)` — use the local date of the original startAt so the date doesn't shift
    3. Calls `onSave(title.trim(), newStartAt.toISOString(), durationMinutes)`
    4. On error: sets error message, stays open

    Delete flow:
    1. User taps "Delete" → `setConfirmDelete(true)`
    2. UI shows "Are you sure?" with "Yes, delete" and "Cancel" buttons
    3. "Yes, delete" → calls `onDelete?.()` → loading → close on success, error message on failure
    4. "Cancel" → `setConfirmDelete(false)` (back to normal edit state)

    Backdrop dismiss:
    - Outer fixed overlay div with `onClick={onCancel}` (backdrop click closes)
    - Inner form container with `onClick={(e) => e.stopPropagation()}` (prevent dismiss when tapping form)

    Swipe-down gesture:
    - Track `touchStart` Y position via `onTouchStart`
    - On `onTouchEnd`, if swipe distance > 60px downward → call `onCancel()`

    Duration stepper:
    - Two buttons: `aria-label="Decrease duration"` and `aria-label="Increase duration"`
    - Each step is 15 minutes; floor at 15, ceiling at 480 (8 hours)
    - Live label showing `"{durationMinutes} min"` (e.g., "30 min")

    Animation:
    - Sheet div has `translate-y-0` when open; use Tailwind `transition-transform duration-300`
    - The sheet is always rendered when TaskSheet is mounted (animation handled by the parent via conditional rendering)

    Layout (Tailwind only, no inline styles except runtime dynamic):
    - Outer: `fixed inset-0 z-50 flex items-end justify-center`
    - Backdrop: `absolute inset-0 bg-black/40` with `onClick={onCancel}`
    - Sheet: `relative w-full max-w-[40rem] bg-white border-t border-zinc-200 rounded-t-xl px-4 pt-4 pb-[calc(2rem+env(safe-area-inset-bottom))] shadow-xl`
    - Swipe handle: `w-10 h-1 rounded-full bg-zinc-300 mx-auto mb-4`
    - Labels: same style as QuickCreateSheet (`text-[0.7rem] font-semibold uppercase tracking-[0.1em] text-zinc-400 mb-1.5`)
    - Save button: same style as QuickCreateSheet (`bg-black text-white`)
    - Cancel button: same style as QuickCreateSheet (border, white bg)
    - Delete button (edit mode, non-confirm state): `w-full border border-red-200 text-red-600 bg-white py-2.5 text-[0.7rem] font-bold uppercase tracking-[0.12em] cursor-pointer transition-colors hover:border-red-400 hover:bg-red-50`
    - Confirm step: two buttons side by side — "Yes, delete" (`bg-red-600 text-white`) and "Cancel" (neutral border)
  </behavior>

    Create `frontend/src/components/tasks/TaskSheet.tsx`.

    Key implementation details:

    1. Import `TimeSlotPicker` from `@/components/tasks/TimeSlotPicker`.
    2. Import `timeToSlotValue` and `slotValueToMinutes` from `@/utils/timeSlots`.
    3. Import `PlannerItem` type from `@/hooks/usePlannerTimeline`.

    For the ISO startAt reconstruction in the submit handler:
    ```ts
    const refDate = new Date(task?.startAt ?? defaultStartAt ?? new Date().toISOString());
    const totalMinutes = slotValueToMinutes(slotValue);
    const newStartAt = new Date(refDate);
    newStartAt.setHours(Math.floor(totalMinutes / 60), totalMinutes % 60, 0, 0);
    await onSave(title.trim(), newStartAt.toISOString(), durationMinutes);
    ```

    For swipe-down gesture, use `useRef` for touchStartY:
    ```ts
    const touchStartYRef = useRef(0);
    const handleTouchStart = (e: React.TouchEvent) => {
      touchStartYRef.current = e.touches[0].clientY;
    };
    const handleTouchEnd = (e: React.TouchEvent) => {
      const delta = e.changedTouches[0].clientY - touchStartYRef.current;
      if (delta > 60) onCancel();
    };
    ```
    Apply `onTouchStart={handleTouchStart}` and `onTouchEnd={handleTouchEnd}` on the sheet div.

    For `useState` initialization that depends on props, use lazy initializer via arrow function
    only if needed; otherwise initialize directly from props in the useState call (props are stable
    for the lifetime of this component instance since parent conditional-renders it).

|----------|-------------|
| TaskSheet delete action | User can delete a task from the edit sheet — guarded by two-step confirm |
| TaskSheet save action | User submits potentially invalid startAt — must construct valid ISO date from slot value + original date |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | TaskSheet delete | mitigate | Two-step "Are you sure?" confirm before onDelete fires; implemented in this plan |
| T-10-03 | Spoofing | ISO date construction in submit | mitigate | Derive date portion from original `task.startAt` or `defaultStartAt`, not from user input — only time portion comes from slotValue |
| T-10-SC | Info Disclosure | Task data in DOM | accept | TaskSheet title/time fields are user-authored; no sensitive server data rendered |
