      ```tsx
        }
      }}
      ```
    - `TaskSheet` rendered conditionally when `isOpen === true`:
      ```tsx
      {isOpen && (
        <TaskSheet
          task={task ?? undefined}
          defaultStartAt={task ? undefined : quickCreateDefaultStartAt}
          defaultDuration={30}
          onSave={async (title, startAt, durationMinutes) => {
            if (mode === 'create') {
              await createScheduledTask(title, startAt, durationMinutes);
            } else if (task) {
              await update(task.id, { title, startAt, duration: durationMinutes });
            }
            close();
            reloadFeed();
          }}
          onDelete={task ? async () => {
            await remove(task.id);
            close();
            reloadFeed();
          } : undefined}
          onCancel={close}
        />
      )}
      ```

    - FAB visibility: change `!showQuickCreate` → `!isOpen` in the FAB condition
    - The `EditTaskModal` block for `editingTask` remains UNCHANGED — it handles sync item editing

    **onSave optimistic pattern:**
    For edit mode saves, the pattern is: close sheet immediately, call update(), call reloadFeed().
    This provides a fast UX (sheet closes instantly) while the feed refreshes in background. On
    error from `update()`, the feed will revert to the original values on reload. For the TaskSheet
    UI, the error state is shown if `onSave` throws (sheet stays open with error message).
